# Thought Collector

Карманный сборник мыслей и дел для Android на React Native и Expo.
Работает офлайн, всё хранится на телефоне в SQLite.

## Зачем

Чтобы записать мысль раньше, чем она забудется, и потом найти её на
нужной полке. Записать можно сразу с главного экрана, без лишних
переходов. Разобрать записи можно позже.

## Что умеет

- **Быстрая запись.** Строка ввода стоит первой на главном экране. После
  сохранения форма остаётся открытой и пустой, потому что за одной мыслью
  обычно приходит следующая.
- **Области.** Записи раскладываются по цветным областям. Запись без
  области попадает в отдельный раздел. Внутри области записи сортируются
  по дате, по алфавиту или вручную.
- **Карточки и жесты.** Нажатие на название открывает редактор, нажатие
  на стрелку сворачивает или разворачивает описание. Долгим нажатием
  карточку можно перетащить, свайпом влево — отправить в корзину.
- **Корзина.** Записи в ней сами не удаляются. Восстановленная область
  забирает обратно записи, которые из неё выпали.
- **Копирование.** Запись или целую область можно скопировать простым
  текстом, чтобы вставить в мессенджер.
- **Бэкап.** Экспорт и импорт всей базы одним JSON-файлом.

## Как устроено

```
App.tsx           три экрана в PagerView: корзина, список, настройки
src/screens/      экраны
src/components/   быстрая запись, карточка со свайпом, редактор, выбор области
src/db.ts         вся работа с SQLite (expo-sqlite): схема, запросы, бэкап
src/events.ts     минимальный pub/sub, чтобы изменения на одном экране
                  сразу появлялись на остальных
src/share.ts      текст для буфера обмена
patches/          правки сторонних библиотек (patch-package)
android/          нативный проект (expo prebuild)
```

- Это порт более ранней версии на Python и Flet. Схема и формат бэкапа
  остались прежними, так что старые данные переносятся обычным импортом.
- Перетаскивание сделано на `react-native-sortables`. Раньше использовался
  `react-native-draggable-flatlist`, но на New Architecture он мигал после
  каждого отпускания карточки. Причину подробно описывает комментарий в
  `ListScreen.tsx`.
- Свайп в корзину написан вручную, без библиотеки: корзина должна лежать
  *под* карточкой, а карточка — следовать за пальцем и после точки
  срабатывания.
- В режиме разработки базу можно открыть на компьютере через Drizzle
  Studio (`expo-drizzle-studio-plugin`).

## Запуск

```
npm install             # заодно применит патчи из patches/
npx expo run:android    # dev-сборка (нужен Android SDK)
npx expo start          # Metro для уже установленной dev-сборки
```

Сборки через EAS настроены в `eas.json`.
